# Brew & Bean

Landing page kedai kopi dengan desain modern dan natural. Proyek ini dibuat sebagai latihan membangun website menggunakan HTML, CSS, dan JavaScript vanilla.

## Demo

[Lihat website Brew & Bean](https://sasakaka.github.io/brew-and-bean/)

## Fitur

- Navbar responsif dengan hamburger menu.
- Hero section dengan tombol navigasi.
- Kartu menu produk kopi.
- About section dan testimoni pelanggan.
- Footer berisi navigasi dan informasi kontak.
- Animasi scroll dan dropdown navbar.

## Teknologi

- HTML5
- CSS3
- JavaScript vanilla
- Google Fonts: Montserrat dan Inter
